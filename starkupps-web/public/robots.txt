# StarKupps storefront — crawler access policy.
#
# DEFAULT: ALLOW (maximum visibility). Search AND AI-search citation bots are
# explicitly allowed so there is never ambiguity about who may fetch, index,
# quote or cite public pages. Private flows (cart/checkout/account/admin/API/
# previews) do not exist as indexable routes in this app — auth and account
# pages carry their own `noindex` meta — so nothing is disallowed here beyond
# the paths below, which are listed defensively.
#
# Training-only crawlers (GPTBot, ClaudeBot, CCBot, Google-Extended,
# Applebot-Extended) are ALLOWED by default. NOTE for the owner: flipping the
# two stanzas marked [TRAINING] to `Disallow: /` opts out of AI *training*
# use. That does NOT affect Google Search or AI Overviews eligibility
# (Google-Extended does not control Search/AI Overviews), but it WILL reduce
# future citation likelihood in ChatGPT/Claude, which learn partly from
# training crawls. Decision recorded 2026-10-10: ALLOW (owner-actions #9).
# Staging/preview deployments must NOT be indexable — serve them with
# `X-Robots-Tag: noindex` or basic auth (Vercel project setting, owner action).
